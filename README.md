An original spot-the-difference game for the desktop browser. Two
near-identical pictures side by side — find every hidden difference.
Three hand-drawn vector scenes (a beach at sunset, a morning market, a
park at night), mouse and keyboard play, hints, timer, score and
synthesised sound. No libraries, no network: every picture is drawn by
the game's own code and every sound is made with WebAudio.

Play it: serve `game/` with any static file server and open
`game/index.html`, or use the GitHub Pages build of this repository.
